# Smart Energy Monitoring & Automated Load Management System

## 📌 Technical Summary
An end-to-end IoT solution engineered to calculate electrical power consumption metrics and enable wireless control over household and industrial loads.

## 🛠️ Architecture & Components
- **Core Controller:** ESP32 Microcontroller
- **Firmware:** Embedded C / C++ (Arduino Framework)
- **Peripherals:** Voltage & Current Sensing Modules, Solid State / Mechanical Relays
